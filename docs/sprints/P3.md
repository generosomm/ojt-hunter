# P3: HTE checker, MOA board, HR emails
Status: Implemented (owner phone check pending)
Goal: Classmates can check a company against the school list, see pending MOA requests, and find usable HR emails.
Scope: `/partnership-checker`, `/moa-board`, `/cold-emails`, a glass dock between sections, company-level publish; excludes creating MOA requests from the app (P6 submissions).
Depends on: P1, P2

## Decisions
- Search runs in Postgres (`search_hte`, `search_companies`, pg_trgm), as the caller, so the HTE public switch still applies.
- Three result states: "On the list" (with the caution that a name match does not prove the entity or campus), "No exact match. Did you mean", and "Not found ... does not mean there is no MOA".
- School links live in the new `resources` table (admin-edited). The MOA request form only exists on Teams and is not reconstructed.
- MOA supporters: each user sees only their own row; the board shows counts from `moa_supporter_counts()`.
- KPMG company published 2026-10-23 so its MOA request shows (part of the owner's publish-all decision). Admins now have a company Publish switch.
