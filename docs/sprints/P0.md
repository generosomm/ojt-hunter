# P0: Setup
Status: In progress
Goal: An empty Next.js 16 app is live on Vercel from a public GitHub repo, connected to Supabase with working Google sign-in.
Scope: scaffold, git + GitHub, Supabase project, Google OAuth client, env vars, Vercel deploy; excludes any tables (P1) and real pages.
Depends on: none

## Steps (owner does the dashboard clicks; Claude gives exact clicks at the time)
1. Scaffold with `npx create-next-app@latest` (TypeScript, Tailwind, App Router, ESLint). It refuses a folder that already has README.md/PRODUCT.md/tests, so scaffold into a temp subfolder with its git setup turned off (confirm the flag with `--help`), move the files up without any nested `.git`, keep these docs and merge `.gitignore`. Add `@supabase/supabase-js` and `@supabase/ssr`.
2. `git init` in `ojt-hunter`, check `git status` shows no `.env*` or `private/`, then make the first commit with `.gitignore` included.
3. Create the **public** GitHub repo on github.com (the `gh` CLI is not installed) and push.
4. Supabase dashboard: new project (region Singapore, closest to PH). Check which key format it issues (newer projects use `sb_publishable_...` / `sb_secret_...` instead of anon / service_role JWTs), align the env names in PROJECT.md and `.env.example`, then put the URL + publishable key in `.env.local`.
5. Google Cloud console: OAuth consent screen (External, scopes `openid email profile` only), create a Web OAuth client with Supabase's callback URL, then **Publish app** so classmates can sign in.
6. Supabase: enable the Google provider, set Site URL and redirect URLs (localhost + Vercel URL).
7. Vercel: import the GitHub repo, add env vars, deploy. Vercel CLI is already installed if preferred.
8. Minimal sign-in / sign-out button on the home page to prove the round trip.

Acceptance:
- [x] `npm run build` passes locally with no TypeScript errors.
- [ ] Vercel URL loads on a phone at 375px.
- [ ] Google sign-in then sign-out works on localhost and on the Vercel URL.
- [ ] Signing in from a Google account that is not a test user works (consent screen published).
- [ ] `git grep` finds no keys; `.env.example` lists names only; service role key not in any client code.
