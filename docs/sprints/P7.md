## Decisions
- Share preview: generated `opengraph-image` (navy, gold chip, tilted glass ID). `metadataBase` comes from Vercel's `VERCEL_PROJECT_PRODUCTION_URL`, so no domain is hardcoded.
- True 404s: the proxy checks role and company slugs as the visitor (so admins still reach drafts) and rewrites missing ones to an unmatched route, which Next serves with status 404 and the "Not here" page.
- robots.txt keeps /me, /admin, /submit and /auth out of search; the sitemap lists public pages plus published roles and companies.
- Analytics: Vercel Web Analytics (cookieless, no personal data), disclosed on /privacy. It records nothing until enabled in the Vercel dashboard.
- Home hero headline renders immediately; only the ID card's numbers stream, in a same-size placeholder (layout shift went from 0.108 to 0.005).
- README rewritten for classmates; developer notes kept short.
