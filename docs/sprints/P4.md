# P4: Profile, tracker, deployment checklist
Status: Implemented (owner phone check pending)
Goal: Each signed-in student keeps a private profile, application tracker and AILPO checklist.
Scope: `/me/tracker`, `/me/checklist`, `/me/profile`, "Save to tracker" on role pages, Me in the dock; excludes templates (P5) and reminders (later).
Depends on: P1, P2

## Decisions
- Google sign-in only (from P0). Signed-out visitors see a sign-in card on every Me page; `/me` redirects to the tracker.
- All saves go through server actions with zod validation; RLS keeps every row owner-only (admins included).
- Forms submit by hand so a failed validation keeps what you typed (React 19 resets plain form actions).
- Tracker: kanban columns on desktop, grouped list on phones (empty groups hidden), status changes by dropdown (no drag and drop). Follow-ups due today or overdue get a gold ring and a banner.
- One card per role per user (partial unique index); manual entries for companies not in the directory.
- Checklist items come from `checklist_templates`; "Can do now" filter; done date uses `app_config.timezone`.
- Owner's own profile and tracker were loaded from `private/seed_my_tracker.sql` (gitignored). "Applied" only where a submission was confirmed.
