# P2: Directory and detail pages
Status: Implemented (owner review pending)
Goal: Anyone with the link can browse published OJT roles, filter them, and open a role or company page.
Scope: home directory with URL filters, role page, company page, admin publish switch, not-found page; excludes tracker, templates, checks and submissions (P4 to P6).
Depends on: P1

## What it does
- Home: hero with the glass intern ID (live counts from the database), search, filters, role cards.
- Filters in the URL (`q, city, role, setup, remote, min, nd, hte, fits, nov, dev, closed, sort`), so a filtered view can be shared.
- Remote is hidden unless "Show remote" is on, and then labeled not allowed. Closed posts hidden unless "Show closed".
- Minimum pay uses the per-day estimate; "not disclosed" is kept only when asked and never sorts as zero.
- "Fits my hours" uses the signed-in user's profile hours, else `app_config.default_required_hours`.
- City options come from the data. Every number and label list comes from the database or `app_config`.
- Role page: pay headline with source text, badges, facts, apply button, details, sources and checks.
- Company page: HTE match with the exact listed name, MOA request, usable emails with copy, a "Do not use" list, roles.
- Admins see drafts (badge) and a Publish switch on the role page. Publishing a role also publishes its company. RLS enforces it.
